# 循环神经网络 RNN 与 LSTM RNN & LSTM

## 一、概念与直觉

循环神经网络(Recurrent Neural Network, RNN)是一类处理**序列数据**的神经网络:它在每个时间步读入一个输入,并维护一个随时间更新的隐藏状态(hidden state),用这个状态把"过去看到的信息"携带到未来。与前馈网络对每个样本独立处理不同,RNN 通过参数在时间维度上的**共享**与状态的**循环传递**,天然适合文本、语音、时间序列等具有先后依赖的数据。

直觉上,可以把 RNN 想象成一个**边读边做笔记**的人:他逐字读一句话,每读一个词就更新脑中的"摘要"(隐藏状态),这个摘要既受当前词影响,也保留了前文。读到句末时,这份摘要就浓缩了整句话的语义。然而普通人记笔记会遗忘久远的细节——这正是朴素 RNN 的痛点:它难以记住相隔很远的依赖。

长短期记忆网络(Long Short-Term Memory, LSTM)是对 RNN 的改进。它额外引入一条贯穿整个序列、几乎不被打断的"传送带"——细胞状态(cell state),并用三个**门(gate)**来精细控制信息的写入、保留与读出。这条传送带让梯度能够长距离传播,从而缓解长依赖难以学习的问题。

## 二、核心知识点

1. **序列建模与参数共享**:RNN 在所有时间步复用同一组权重,使模型能处理任意长度序列,参数量不随序列长度增长。
2. **隐藏状态的递归**:$h_t$ 同时依赖当前输入 $x_t$ 和上一时刻状态 $h_{t-1}$,实现对历史的记忆。
3. **沿时间反向传播(BPTT)**:训练通过把网络在时间上展开(unroll)再做反向传播,梯度需穿过多个时间步累乘。
4. **梯度消失/爆炸**:重复乘以同一权重矩阵导致梯度按指数衰减或增长,是朴素 RNN 难学长依赖的根本原因。
5. **梯度裁剪(gradient clipping)**:对梯度范数设上限,主要用于抑制梯度爆炸,但不能解决梯度消失。
6. **LSTM 的细胞状态**:$C_t$ 以加性更新为主,提供"恒定误差流"通道,使梯度更易长距离传播。
7. **三门机制**:遗忘门(forget)决定丢弃多少旧记忆,输入门(input)决定写入多少新信息,输出门(output)决定暴露多少记忆给隐藏状态。
8. **GRU 简化版**:门控循环单元(GRU)合并细胞与隐藏状态,只用更新门和重置门,参数更少、训练更快。
9. **变体结构**:双向 RNN(BiRNN)同时利用前后文;堆叠多层 RNN 可增强表达能力。
10. **应用范式**:一对多、多对一、多对多(含 seq2seq 编码器-解码器),覆盖分类、生成、翻译等任务。

## 三、关键公式 / 原理

**朴素 RNN** 的前向传播(以 tanh 为例):

$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h), \quad y_t = W_{hy} h_t + b_y$$

- $x_t$:第 $t$ 步输入;$h_t$:第 $t$ 步隐藏状态;$y_t$:输出。
- $W_{xh}, W_{hh}, W_{hy}$:输入到隐藏、隐藏到隐藏、隐藏到输出的权重,所有时间步共享。
- $b_h, b_y$:偏置;$\tanh$ 把激活压到 $(-1,1)$。

**梯度消失的根源**:BPTT 中 $\partial h_t / \partial h_k$ 包含连乘 $\prod_{i=k+1}^{t} W_{hh}^{\top}\, \mathrm{diag}(\tanh'(\cdot))$。当该乘积的谱半径小于 1 时梯度按指数衰减,大于 1 时爆炸。

**LSTM** 的核心方程($\sigma$ 为 sigmoid,$\odot$ 为逐元素乘):

$$f_t = \sigma(W_f[h_{t-1}, x_t] + b_f) \quad \text{(遗忘门)}$$
$$i_t = \sigma(W_i[h_{t-1}, x_t] + b_i), \quad \tilde{C}_t = \tanh(W_C[h_{t-1}, x_t] + b_C) \quad \text{(输入门与候选)}$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{(细胞状态更新)}$$
$$o_t = \sigma(W_o[h_{t-1}, x_t] + b_o), \quad h_t = o_t \odot \tanh(C_t) \quad \text{(输出门与隐藏状态)}$$

关键在 $C_t = f_t \odot C_{t-1} + \dots$ 这一**加性**更新:当 $f_t \approx 1$ 时旧记忆几乎无损流过,梯度对 $C_{t-1}$ 的导数接近 $f_t$,避免了乘性连乘带来的快速衰减。

## 四、典型例子 / 推导

考虑一个标量 LSTM 单元,处理两步序列,目标是"记住"第一步的信息。设初始 $C_0 = 0$。

第 1 步:输入 $x_1$ 带来候选 $\tilde{C}_1 = 0.8$。设遗忘门 $f_1 = 0.9$,输入门 $i_1 = 1.0$。
$$C_1 = f_1 \cdot C_0 + i_1 \cdot \tilde{C}_1 = 0.9 \times 0 + 1.0 \times 0.8 = 0.8$$

第 2 步:假设此步无新信息,候选 $\tilde{C}_2 = 0$,网络学到要"保持记忆",故 $f_2 = 1.0$,$i_2 = 0$。
$$C_2 = f_2 \cdot C_1 + i_2 \cdot \tilde{C}_2 = 1.0 \times 0.8 + 0 = 0.8$$

可见第一步写入的 0.8 被原样保留到第二步。再看输出门:若 $o_2 = 0.5$,则
$$h_2 = o_2 \cdot \tanh(C_2) = 0.5 \times \tanh(0.8) \approx 0.5 \times 0.664 = 0.332$$

对比朴素 RNN:若 $h_t = \tanh(0.5\, h_{t-1})$,从 $h_0 = 0.8$ 出发,几步后会迅速被 tanh 反复压缩而趋近 0,信息很快丢失。这直观说明:LSTM 通过门控让"保持"成为一种可学习、可长期维持的行为,而朴素 RNN 的状态在每步都被非线性挤压。

## 五、常见误区

1. **"LSTM 彻底消除了梯度消失"**:错。LSTM 大幅缓解但不能保证消除;当遗忘门长期接近 0 时记忆仍会丢失,极长序列依然可能退化。
2. **"梯度裁剪能解决梯度消失"**:错。裁剪只限制梯度上界,针对爆炸有效;消失需靠门控结构、合适初始化或残差连接来缓解。
3. **"RNN 每个时间步用不同的权重"**:错。同一层的权重在所有时间步共享,这正是 RNN 能泛化到变长序列的前提。
4. **"细胞状态 $C_t$ 就是输出"**:错。对外输出和传给下一步的隐藏状态是 $h_t = o_t \odot \tanh(C_t)$,$C_t$ 是内部记忆,需经输出门过滤。
5. **"门的取值是 0 或 1 的硬开关"**:错。门由 sigmoid 给出,取连续值 $(0,1)$,表示"部分通过",可微才能端到端训练。
6. **"双向 RNN 可用于实时/在线预测"**:错。BiRNN 需要完整序列(含未来)才能计算后向部分,不适合只有历史可见的流式场景。

## 六、与其他知识点的联系

**前置知识**:多层感知机与反向传播(理解 BPTT 的基础)、激活函数(sigmoid/tanh 的饱和特性)、链式法则与矩阵求导、softmax 与交叉熵(序列输出的损失)。

**横向关联**:LSTM 与 GRU 同属门控 RNN,可对比取舍;梯度消失问题与深层网络中的残差连接(ResNet)思想相通——都是用"恒等/加性"通路保住梯度。

**后续延伸**:seq2seq 编码器-解码器引出**注意力机制(Attention)**,而注意力进一步催生了**Transformer**,后者用自注意力替代循环结构,实现并行计算与更强的长程建模,如今在 NLP 中已大体取代 RNN。理解 RNN 的局限,正是理解 Transformer 设计动机的关键一环。

## 七、自测题(含参考答案)

**1.(选择)** 朴素 RNN 难以学习长距离依赖,最根本的原因是?
A. 参数太多 B. BPTT 中梯度沿时间连乘导致指数衰减/增长 C. 隐藏层维度太小 D. 使用了 ReLU
**参考答案:B**。解析:梯度穿过多个时间步时反复乘以 $W_{hh}$ 与激活导数,谱半径偏离 1 即引发消失或爆炸,与参数数量或维度无直接因果。

**2.(判断)** "LSTM 的细胞状态更新 $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ 是加性的,这有助于梯度长距离传播。"
**参考答案:正确**。解析:加性更新使 $\partial C_t / \partial C_{t-1} \approx f_t$,当遗忘门接近 1 时梯度近似恒等传递,避免乘性连乘的快速衰减。

**3.(简答)** 简述 LSTM 三个门各自的作用。
**参考答案**:遗忘门 $f_t$ 控制保留多少上一时刻细胞记忆;输入门 $i_t$ 控制写入多少当前候选信息 $\tilde{C}_t$;输出门 $o_t$ 控制把多少经 tanh 处理的细胞状态暴露为隐藏状态 $h_t$。三者均由 sigmoid 产生 $(0,1)$ 的连续权重。

**4.(计算)** 某标量 LSTM 单元,$C_{t-1}=0.5$,$f_t=0.6$,$i_t=0.8$,候选 $\tilde{C}_t=0.5$,输出门 $o_t=1.0$。求 $C_t$ 与 $h_t$(取 $\tanh(0.7)\approx 0.604$)。
**参考答案**:$C_t = 0.6\times0.5 + 0.8\times0.5 = 0.3 + 0.4 = 0.7$;$h_t = o_t \cdot \tanh(C_t) = 1.0 \times 0.604 = 0.604$。解析:先按加性公式求细胞状态,再经输出门与 tanh 得到隐藏状态。
