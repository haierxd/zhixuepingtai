# 逻辑回归与分类 Logistic Regression & Classification

## 一、概念与直觉

逻辑回归(Logistic Regression)是一种用于**分类(classification)**的监督学习模型:尽管名字里有"回归",它解决的却是分类问题。它先对输入特征做线性组合,再通过一个 sigmoid 函数把结果压缩到 \([0,1]\) 区间,从而输出"样本属于正类的概率"。

可以把它想象成一道**带置信度的开关**。线性回归直接预测一个连续值(比如房价),而逻辑回归回答的是"是/否"类问题,并给出把握有多大:这封邮件是垃圾邮件的概率是 0.92,这位用户会流失的概率是 0.13。我们给一个阈值(通常 0.5),概率超过阈值就判为正类。

它之所以是入门必学,是因为它结构简单、可解释性强(每个权重直接反映特征对结果的影响方向与大小),且是理解神经网络的关键一步——一个逻辑回归单元本质上就是一个带 sigmoid 激活的人工神经元。

## 二、核心知识点

1. 逻辑回归是**判别式(discriminative)分类模型**,直接建模条件概率 \(P(y\mid x)\),而非联合分布。
2. 它通过 **sigmoid(logistic)函数** \(\sigma(z)=1/(1+e^{-z})\) 将线性得分映射为概率,曲线呈 S 形,\(\sigma(0)=0.5\)。
3. 决策边界是**线性的**:\(w^\top x + b = 0\) 这个超平面把空间分成两类。
4. 损失函数用**交叉熵 / 对数损失(log loss)**,而非均方误差,因为前者对 sigmoid 是凸的,优化更稳定。
5. 参数通过**极大似然估计(MLE)**求解,等价于最小化交叉熵损失。
6. 无解析解,需用**梯度下降(gradient descent)**等迭代优化方法求参数。
7. 特征通常需要**标准化/归一化**,否则不同量纲会拖慢收敛。
8. 多分类用 **Softmax 回归**(多项逻辑回归)推广,输出各类别概率且和为 1。
9. 可加 **L1/L2 正则化**防止过拟合,L1 还能做特征选择。
10. 权重 \(w_j\) 的含义:在 logit(对数几率)尺度上,\(x_j\) 每增加一个单位,对数几率改变 \(w_j\)。

## 三、关键公式 / 原理

**模型输出**(以二分类为例):

\[ \hat{y} = P(y=1\mid x) = \sigma(w^\top x + b) = \frac{1}{1+e^{-(w^\top x + b)}} \]

- \(x\):特征向量;\(w\):权重向量;\(b\):偏置;\(\sigma\):sigmoid 函数。

**对数几率(logit)**:模型本质是对 log-odds 做线性回归

\[ \log\frac{P(y=1\mid x)}{P(y=0\mid x)} = w^\top x + b \]

**交叉熵损失**(单样本,\(y\in\{0,1\}\)):

\[ L = -\big[\,y\log\hat{y} + (1-y)\log(1-\hat{y})\,\big] \]

\(N\) 个样本取平均即为总损失。当真实标签为 1 而预测接近 0 时,损失趋于无穷,起到强惩罚作用。

**梯度与参数更新**:对单个样本,损失对 \(w\) 的梯度恰好是

\[ \nabla_w L = (\hat{y}-y)\,x \]

形式简洁。用学习率 \(\eta\) 做梯度下降:

\[ w := w - \eta\,(\hat{y}-y)\,x \]

## 四、典型例子 / 推导

设单特征模型,参数 \(w=2,\ b=-3\),学习率 \(\eta=0.1\)。样本 \(x=2,\ y=1\)(真实为正类)。

第一步,前向计算线性得分:\(z = wx+b = 2\times2-3 = 1\)。

第二步,过 sigmoid:\(\hat{y}=\sigma(1)=\frac{1}{1+e^{-1}}\approx \frac{1}{1+0.3679}\approx 0.731\)。即模型认为该样本属于正类的概率约 73.1%,因 \(0.731>0.5\),预测为正类,方向正确但置信度还不够。

第三步,计算损失:\(L=-\log(0.731)\approx 0.313\)。

第四步,计算梯度并更新参数:
- 误差 \(\hat{y}-y = 0.731-1 = -0.269\)
- \(\nabla_w L=(\hat{y}-y)x=-0.269\times2=-0.538\),则 \(w := 2-0.1\times(-0.538)=2.054\)
- \(\nabla_b L=\hat{y}-y=-0.269\),则 \(b := -3-0.1\times(-0.269)=-2.973\)

更新后 \(w\) 增大、\(b\) 增大,再算 \(z=2.054\times2-2.973=1.135\),\(\hat{y}=\sigma(1.135)\approx0.757\),概率上升、损失下降。反复迭代,模型逐步逼近最优参数。

## 五、常见误区

1. **"逻辑回归是回归算法"**:错。它输出概率并用于分类,属于分类模型;"回归"指的是对 logit 做线性建模这一历史命名。
2. **用均方误差(MSE)做损失**:错。MSE 配 sigmoid 会得到非凸损失、梯度易消失;正确做法是交叉熵损失,它对参数是凸的。
3. **"输出 0.7 就代表 70% 的确定性已校准"**:不一定。未经校准的概率只是相对排序可靠,绝对数值未必准确,需要时应做概率校准(如 Platt scaling)。
4. **认为决策边界是曲线**:在原始特征空间中边界是线性超平面;要拟合非线性边界需手动构造多项式/交互特征或换模型。
5. **忽略特征标准化**:不同量纲会使梯度下降在某些方向上震荡、收敛缓慢,且正则化惩罚不公平。
6. **阈值固定为 0.5 永不变**:0.5 只是默认值;类别不平衡或代价不对称时,应根据精确率/召回率需求调整阈值。

## 六、与其他知识点的联系

**前置知识**:线性回归(线性组合 \(w^\top x+b\) 的思想)、概率与极大似然估计、微积分中的求导与链式法则、梯度下降优化。

**横向关联**:与 Softmax 回归是二分类与多分类的关系;与朴素贝叶斯同为概率分类器,但前者是判别式、后者是生成式;与支持向量机(SVM)都给出线性决策边界,但损失函数(log loss vs. hinge loss)不同。

**后续延伸**:逻辑回归单元加 sigmoid 激活即神经网络的基本神经元,多个堆叠并换非线性激活就成为多层感知机(MLP)与深度网络;评估部分自然引出混淆矩阵、精确率/召回率、ROC 曲线与 AUC。

## 七、自测题(含参考答案)

**1.(判断)** 逻辑回归的决策边界在原始特征空间中一定是线性的。
**参考答案**:正确。
**解析**:判别准则 \(w^\top x+b=0\) 是一个超平面,故边界线性;非线性需靠特征变换或换模型。

**2.(选择)** 逻辑回归通常使用哪种损失函数?
A. 均方误差 B. 交叉熵 C. Hinge 损失 D. 绝对误差
**参考答案**:B。
**解析**:交叉熵(对数损失)由极大似然推导而来,且对参数为凸,优化稳定;MSE 配 sigmoid 非凸。

**3.(计算)** 已知 \(w=1,b=0,x=0\),求模型输出概率 \(\hat{y}\),并判断预测类别(阈值 0.5)。
**参考答案**:\(\hat{y}=\sigma(0)=0.5\);恰处边界,通常约定判为正类或视为不确定。
**解析**:\(z=1\times0+0=0\),\(\sigma(0)=1/(1+e^0)=0.5\),正好落在决策边界上。

**4.(简答)** 为什么逻辑回归不能直接用线性回归的输出做分类?
**参考答案**:线性回归输出范围是整个实数轴,不能解释为概率,且对极端值敏感、决策不稳定。逻辑回归用 sigmoid 把得分压到 \([0,1]\),既可解释为概率,又配合交叉熵得到凸优化目标。
**解析**:关键在于"概率语义"与"凸损失"两点,这正是 sigmoid + 交叉熵组合的价值。
