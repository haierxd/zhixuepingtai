# 损失函数与梯度下降 Loss Functions & Gradient Descent

## 一、概念与直觉

**损失函数(Loss Function)** 是衡量模型预测值与真实值差距的标量函数;**梯度下降(Gradient Descent)** 则是通过沿损失函数负梯度方向迭代更新参数,使损失逐步减小的优化算法。两者构成了几乎所有监督学习训练的核心:损失函数定义了"什么是好",梯度下降负责"如何变好"。

可以把训练过程想象成在浓雾中下山:你看不见整座山的全貌(无法直接求出全局最优),但能感知脚下哪个方向最陡(梯度),于是每一步都朝最陡的下坡方向走一小步,反复迭代,最终走到山谷低处。山的高度就是损失,你的位置就是模型参数,步长就是学习率(learning rate)。

需要强调的是,损失函数针对单个样本(或一批样本)的误差,而由全体训练样本损失平均得到的整体目标常称为**代价函数(Cost Function)** 或**目标函数(Objective Function)**;在实践中二者常被混用,但理解其层次有助于厘清"优化谁"。

## 二、核心知识点

1. **回归常用 MSE**:均方误差(Mean Squared Error)对大误差惩罚更重,对应高斯噪声下的极大似然估计。
2. **分类常用交叉熵**:交叉熵损失(Cross-Entropy)衡量预测分布与真实分布的差距,配合 softmax/sigmoid 使用,梯度形式简洁。
3. **梯度方向**:梯度 $\nabla L$ 指向函数值上升最快的方向,因此参数更新取**负梯度**方向。
4. **学习率 $\eta$ 至关重要**:过大易震荡或发散,过小则收敛缓慢,常需调参或使用学习率调度(scheduling)。
5. **三种批量形式**:批量梯度下降(BGD,用全部数据)、随机梯度下降(SGD,用单样本)、小批量(Mini-batch,用一个 batch)是工程标配。
6. **凸与非凸**:线性/逻辑回归的损失是凸函数,有全局最优;神经网络损失非凸,只能找到较好的局部最优。
7. **反向传播是求梯度的手段**:Backpropagation 利用链式法则高效计算复合函数对各参数的梯度,本身不是优化算法。
8. **正则化项**:L1/L2 正则可加入损失函数以抑制过拟合,改变了被优化的目标。
9. **优化器进阶**:Momentum、AdaGrad、RMSProp、Adam 在朴素梯度下降基础上改进步长与方向。
10. **损失要可微(或次可微)**:梯度下降依赖梯度存在,这也是为何分类训练用交叉熵而非直接优化准确率。

## 三、关键公式 / 原理

**参数更新规则(核心):**

$$w := w - \eta \nabla_w L(w)$$

- $w$:模型参数(权重);$:=$ 表示赋值更新。
- $\eta$:学习率(步长),正的小常数。
- $\nabla_w L(w)$:损失 $L$ 对参数 $w$ 的梯度向量。

**均方误差(MSE):**

$$L_{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

- $n$:样本数;$y_i$:第 $i$ 个真实值;$\hat{y}_i$:第 $i$ 个预测值。

**二分类交叉熵(Binary Cross-Entropy):**

$$L_{CE} = -\frac{1}{n}\sum_{i=1}^{n}\big[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\big]$$

- $y_i \in \{0,1\}$:真实标签;$\hat{y}_i \in (0,1)$:模型预测为正类的概率。

**原理**:在 $w$ 处对 $L$ 做一阶泰勒展开,$L(w-\eta\nabla L)\approx L(w)-\eta\|\nabla L\|^2$,只要 $\eta$ 足够小,负梯度方向就能保证损失下降。

## 四、典型例子 / 推导

考虑最简单的线性模型 $\hat{y}=wx$(无偏置),用 MSE 训练,单样本损失 $L=(y-wx)^2$。

设训练样本 $(x,y)=(2,\,6)$,初始 $w_0=1$,学习率 $\eta=0.05$。

**第 0 步**:预测 $\hat{y}=w_0 x=1\times 2=2$,误差 $y-\hat{y}=6-2=4$,损失 $L=4^2=16$。

求梯度:$\dfrac{\partial L}{\partial w}=2(y-wx)\cdot(-x)=-2x(y-wx)=-2\times 2\times 4=-16$。

更新:$w_1 = w_0 - \eta\cdot\dfrac{\partial L}{\partial w}=1-0.05\times(-16)=1+0.8=1.8$。

**第 1 步**:预测 $\hat{y}=1.8\times 2=3.6$,误差 $6-3.6=2.4$,损失 $L=2.4^2=5.76$(已从 16 降到 5.76)。

梯度 $=-2\times 2\times 2.4=-9.6$,更新 $w_2=1.8-0.05\times(-9.6)=1.8+0.48=2.28$。

可见 $w$ 正逐步逼近理论最优解 $w^*=y/x=3$,损失单调下降。这就是梯度下降"一步步逼近最优"的全过程。

## 五、常见误区

1. **"梯度下降找到的一定是全局最优"**:错。仅对凸函数成立;神经网络非凸,通常只得局部最优或鞍点附近的解。
2. **"学习率越小越好"**:错。过小会导致收敛极慢甚至在限定迭代内无法到位;需要在稳定与速度间权衡。
3. **"反向传播就是梯度下降"**:错。反向传播只负责**计算梯度**,梯度下降负责**用梯度更新参数**,二者分工不同。
4. **"分类问题可以直接用 MSE"**:不推荐。配合 sigmoid 时 MSE 易使梯度饱和(梯度消失),交叉熵的梯度更稳定、收敛更快。
5. **"梯度指向损失最小的方向"**:错。梯度指向**上升**最快方向,所以更新时要取负号。
6. **"SGD 的损失曲线应当平滑下降"**:不一定。SGD/Mini-batch 因采样噪声,损失曲线会有抖动,整体趋势下降即可。

## 六、与其他知识点的联系

**前置知识**:多元微积分(偏导数、梯度、链式法则)、线性代数(向量与矩阵运算)、概率论(极大似然估计,用于理解 MSE 与交叉熵的由来)。

**并列/支撑**:损失函数的选择与具体模型(线性回归、逻辑回归、神经网络)紧密耦合;反向传播是神经网络中计算梯度的关键算法。

**后续延伸**:由朴素 SGD 衍生出 Momentum、Adam 等现代优化器;学习率调度、批归一化(BatchNorm)、梯度裁剪等训练技巧;以及正则化、过拟合与泛化等模型评估主题。掌握本主题是理解深度学习训练全流程(前向传播 → 计算损失 → 反向传播 → 参数更新)的枢纽。

## 七、自测题(含参考答案)

**1.(选择)** 在梯度下降的更新公式 $w := w - \eta\nabla L$ 中,使用负梯度的原因是?
A. 梯度指向损失下降最快的方向 B. 梯度指向损失上升最快的方向 C. 习惯写法,无实际意义 D. 为了让学习率变正

**参考答案:B**。解析:梯度指向函数值上升最快的方向,要减小损失须沿其反方向移动,故取负号。

**2.(判断)** 交叉熵损失要求模型输出为概率(取值在 0 到 1 之间)。( )

**参考答案:正确**。解析:交叉熵中含 $\log\hat{y}$ 项,需 $\hat{y}\in(0,1)$,因此分类任务常用 sigmoid/softmax 将输出归一化为概率。

**3.(简答)** SGD 与 BGD 相比有何优缺点?

**参考答案**:SGD 每次只用一个(或少量)样本估计梯度,更新快、内存省、能借噪声跳出较差的局部最优,但收敛路径抖动大;BGD 用全部数据,梯度准确、下降平滑,但每步计算量大、内存压力高,且易陷入局部最优。实践中多用折中的 Mini-batch GD。

**4.(计算)** 对单样本 MSE 损失 $L=(y-wx)^2$,已知 $x=3,\,y=12,\,w=2,\,\eta=0.01$,求一步更新后的 $w$。

**参考答案**:$\hat{y}=wx=6$,误差 $=12-6=6$;梯度 $\dfrac{\partial L}{\partial w}=-2x(y-wx)=-2\times3\times6=-36$;更新 $w:=2-0.01\times(-36)=2+0.36=2.36$。解析:沿负梯度方向 $w$ 增大,向最优解 $w^*=12/3=4$ 靠拢。
