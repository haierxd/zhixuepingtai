# 监督学习与无监督学习 Supervised vs Unsupervised Learning

## 一、概念与直觉

监督学习(Supervised Learning)是指训练数据中既有输入特征 $x$ 又有对应的标签 $y$,模型的目标是学习一个从输入到输出的映射 $f: x \mapsto y$,使其在未见过的数据上也能给出准确预测。无监督学习(Unsupervised Learning)的训练数据只有输入 $x$ 没有标签 $y$,目标是从数据自身的结构中发现规律,如分组、降维或密度估计。

打个比方:监督学习像是有老师批改作业的学习——每道题都有标准答案,你通过对照答案来修正自己的解法;无监督学习则像把一堆没有标签的照片交给你,要你按"看起来相似"自行归类,没人事先告诉你应该分成几类、每类叫什么。

两者并非对立,而是覆盖了机器学习的不同任务谱系。此外还有介于两者之间的半监督学习(少量标签 + 大量无标签)和以奖励信号为反馈的强化学习,但入门阶段先把监督与无监督这条主线理清最为关键。

## 二、核心知识点

1. 监督学习需要带标签数据 $(x_i, y_i)$,无监督学习只用无标签数据 $x_i$。
2. 监督学习两大任务:分类(classification,$y$ 离散)与回归(regression,$y$ 连续)。
3. 无监督学习的典型任务:聚类(clustering)、降维(dimensionality reduction)、密度估计与异常检测。
4. 监督学习的核心是最小化预测值与真实标签之间的损失函数(loss function),如平方损失、交叉熵。
5. 无监督学习没有真实标签,因此优化目标来自数据内部结构,如簇内距离、重构误差。
6. 泛化(generalization)是监督学习的核心关切:用训练集学习,在测试集上评估,警惕过拟合(overfitting)。
7. 常见监督算法:线性/逻辑回归、k 近邻、决策树、SVM、神经网络。
8. 常见无监督算法:K-means、层次聚类、PCA、自编码器(autoencoder)、GMM。
9. 评估方式不同:监督用准确率、F1、MSE 等对照标签的指标;无监督常用轮廓系数、重构误差等无标签内部指标。
10. 半监督学习结合少量标签与大量无标签数据,常用于标注成本高的场景。

## 三、关键公式 / 原理

监督学习的一般目标是经验风险最小化(Empirical Risk Minimization):

$$\min_{\theta} \; \frac{1}{N} \sum_{i=1}^{N} L\big(f_\theta(x_i),\, y_i\big) + \lambda R(\theta)$$

其中 $f_\theta$ 是参数为 $\theta$ 的模型;$L$ 是损失函数(回归常用平方损失 $L=(\hat y - y)^2$,分类常用交叉熵);$R(\theta)$ 是正则项,$\lambda$ 控制正则强度以抑制过拟合;$N$ 为样本数。参数通过梯度下降更新:$w := w - \eta \nabla L$,其中 $\eta$ 是学习率。

无监督的 K-means 目标是最小化簇内平方和(within-cluster sum of squares):

$$\min_{C,\mu} \; \sum_{k=1}^{K} \sum_{x \in C_k} \lVert x - \mu_k \rVert^2$$

其中 $K$ 是簇数,$C_k$ 是第 $k$ 个簇,$\mu_k$ 是其质心。算法交替执行:固定质心把每个点分到最近簇(assignment),再用各簇均值更新质心(update),直到收敛。注意这里没有任何 $y$ 参与。

## 四、典型例子 / 推导

以 K-means 在一维数据上手算一轮为例。数据点:$\{1, 2, 8, 9\}$,设 $K=2$,初始质心 $\mu_1 = 1$,$\mu_2 = 8$。

第一步(分配):
- 点 1:到 $\mu_1$ 距离 0,到 $\mu_2$ 距离 7,归入簇 1。
- 点 2:到 $\mu_1$ 距离 1,到 $\mu_2$ 距离 6,归入簇 1。
- 点 8:到 $\mu_1$ 距离 7,到 $\mu_2$ 距离 0,归入簇 2。
- 点 9:到 $\mu_1$ 距离 8,到 $\mu_2$ 距离 1,归入簇 2。

得到 $C_1 = \{1, 2\}$,$C_2 = \{8, 9\}$。

第二步(更新质心):$\mu_1 = (1+2)/2 = 1.5$,$\mu_2 = (8+9)/2 = 8.5$。

再做一轮分配,各点归属不变,算法收敛。最终簇内平方和为 $(1-1.5)^2 + (2-1.5)^2 + (8-8.5)^2 + (9-8.5)^2 = 0.25 \times 4 = 1.0$。整个过程没有用到任何标签,这正是无监督的特征。

## 五、常见误区

1. "无监督就是没有目标函数"——错。无监督同样在优化目标(如簇内距离、重构误差),只是目标不依赖外部标签。
2. "分类和回归都是监督,所以聚类就是分类"——错。聚类无标签、簇的语义需事后人工解释;分类有预定义类别且训练时已知。
3. "K-means 一定收敛到全局最优"——错。它只保证收敛到局部最优,结果对初始质心敏感,故常用 k-means++ 初始化并多次重启。
4. "标签越多模型一定越好"——不一定。标签噪声、数据分布偏移、过拟合都会削弱效果,质量与代表性比数量更关键。
5. "降维(如 PCA)是监督学习"——错。标准 PCA 只用 $x$ 的协方差结构,不使用 $y$,属于无监督;它与有监督的 LDA 要区分开。
6. "训练集上准确率高就说明模型好"——错。必须在独立测试集上评估泛化能力,训练集高分可能只是过拟合。

## 六、与其他知识点的联系

前置知识:线性代数(向量、矩阵、距离与内积)、概率与统计(期望、分布、最大似然)、微积分(梯度,用于优化)。理解损失函数与梯度下降是打通监督学习的钥匙。

向后延伸:监督学习通往逻辑回归、SVM、决策树与集成方法,直至深度神经网络与 CNN/Transformer;无监督学习通往 PCA、GMM、自编码器,并与生成模型(VAE、GAN、扩散模型)相连。两条线在表示学习(representation learning)与自监督学习(self-supervised learning)处汇合——后者用无标签数据构造"伪标签"任务,是大模型预训练的基础。模型评估、偏差-方差权衡、正则化则是贯穿两类方法的通用主题。

## 七、自测题(含参考答案)

**1.(判断)** PCA 在执行时使用了样本标签 $y$。

参考答案:错误。解析:标准 PCA 仅基于输入特征的协方差矩阵做特征分解,不使用标签,属于无监督降维;使用标签做降维的是 LDA。

**2.(选择)** 下列哪项属于无监督学习任务?
A. 房价预测  B. 垃圾邮件分类  C. 用户分群聚类  D. 手写数字识别

参考答案:C。解析:A 是回归,B、D 是分类,均需标签;只有 C 在无标签下按相似性分组。

**3.(简答)** 简述监督学习与无监督学习在数据和目标上的根本区别。

参考答案:监督学习数据为 $(x, y)$ 成对带标签,目标是学习映射 $f: x \mapsto y$ 并最小化对标签的预测损失;无监督学习数据仅含 $x$,目标是发现数据内部结构(分组、降维、密度),优化目标不依赖外部标签。

**4.(计算)** 对数据 $\{2, 4, 10, 12\}$,$K=2$,初始质心 $\mu_1=2$、$\mu_2=12$,执行一轮 K-means 后两个质心各为多少?

参考答案:$\mu_1 = 3$,$\mu_2 = 11$。解析:点 2、4 离 $\mu_1$ 更近成簇 1,点 10、12 离 $\mu_2$ 更近成簇 2;更新得 $\mu_1=(2+4)/2=3$,$\mu_2=(10+12)/2=11$。
