# 人工智能与机器学习概览 AI & Machine Learning Overview

## 一、概念与直觉

人工智能(Artificial Intelligence, AI)是研究如何让机器完成通常需要人类智能才能完成的任务的学科;机器学习(Machine Learning, ML)是实现 AI 的主流方法之一,核心思想是"从数据中自动学习规律,而不是由人手工编写全部规则"。深度学习(Deep Learning)则是机器学习中以多层神经网络为模型的一个分支。三者是包含关系:AI ⊃ ML ⊃ DL。

可以用"学骑自行车"来建立直觉:传统编程像是有人把每一步操作写成说明书让你照做,而机器学习像是你自己反复尝试、摔倒、调整,逐渐在数据(经验)中找到平衡的规律。我们不直接告诉模型"什么是猫",而是给它大量带标签的图片,让它自己总结出区分猫与非猫的特征。

更形式化地说(Mitchell 的定义):若一个程序在任务 T 上的性能度量 P 随经验 E 的增加而提高,就称它在从经验 E 中学习。这把"学习"变成了可度量、可优化的工程问题。

## 二、核心知识点

1. 机器学习按反馈类型分为三大范式:监督学习(Supervised Learning)、无监督学习(Unsupervised Learning)、强化学习(Reinforcement Learning)。
2. 监督学习使用带标签数据,目标是学习从输入 X 到输出 Y 的映射;按 Y 的类型分为分类(离散标签)与回归(连续值)。
3. 无监督学习只有输入没有标签,常见任务包括聚类(Clustering)、降维(如 PCA)、密度估计。
4. 模型(Model)是带参数的假设函数;训练(Training)就是用数据调整参数,使损失函数(Loss Function)最小。
5. 损失函数衡量预测与真实值的差距,如回归常用均方误差(MSE),分类常用交叉熵(Cross-Entropy)。
6. 优化通常用梯度下降(Gradient Descent):沿损失对参数的负梯度方向迭代更新参数。
7. 数据集需划分为训练集、验证集、测试集;测试集只用于最终评估,绝不能参与训练或调参。
8. 泛化(Generalization)是核心目标:模型在未见过数据上的表现,而非只在训练集上拟合得好。
9. 欠拟合(Underfitting)指模型太简单学不到规律;过拟合(Overfitting)指模型记住了训练集噪声而泛化差。
10. 偏差-方差权衡(Bias-Variance Tradeoff)解释了模型复杂度与泛化误差之间的关系。

## 三、关键公式 / 原理

线性回归的假设函数:$\hat{y} = w^\top x + b$,其中 $x$ 是特征向量,$w$ 是权重,$b$ 是偏置,$\hat{y}$ 是预测值。

均方误差损失(对 $m$ 个样本):
$L(w,b) = \frac{1}{m}\sum_{i=1}^{m}(\hat{y}^{(i)} - y^{(i)})^2$

其中 $y^{(i)}$ 是第 $i$ 个样本的真实标签,$\hat{y}^{(i)}$ 是其预测值。

梯度下降的参数更新规则:
$w := w - \eta \nabla_w L$

其中 $\eta$ 是学习率(Learning Rate),控制每步更新的幅度;$\nabla_w L$ 是损失对 $w$ 的梯度。学习率过大会震荡甚至发散,过小则收敛太慢。

二分类常用 Sigmoid 与交叉熵:$\sigma(z) = \frac{1}{1+e^{-z}}$,损失 $L = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$,其中 $\hat{y}=\sigma(w^\top x + b)$ 是预测为正类的概率。

## 四、典型例子 / 推导

用一元线性回归 $\hat{y} = wx$(省略 $b$)做一步梯度下降。设两个样本:$(x_1,y_1)=(1,2)$、$(x_2,y_2)=(2,4)$,初始 $w=0$,学习率 $\eta=0.1$。

第一步,计算预测:$\hat{y}_1 = 0\cdot1 = 0$,$\hat{y}_2 = 0\cdot2 = 0$。

损失 $L = \frac{1}{2}[(0-2)^2 + (0-4)^2] = \frac{1}{2}(4+16) = 10$。

对 $w$ 求梯度:$\frac{\partial L}{\partial w} = \frac{1}{m}\sum 2(\hat{y}^{(i)}-y^{(i)})x^{(i)} = \frac{1}{2}[2(0-2)(1) + 2(0-4)(2)] = \frac{1}{2}[-4-16] = -10$。

更新:$w := 0 - 0.1\times(-10) = 1$。

验证改进:新预测 $\hat{y}_1=1$,$\hat{y}_2=2$,新损失 $L=\frac{1}{2}[(1-2)^2+(2-4)^2]=\frac{1}{2}(1+4)=2.5$,从 10 降到 2.5,损失确实下降。继续迭代会趋近真实解 $w=2$。

## 五、常见误区

1. 把测试集用于调参或特征选择。错在造成数据泄露(Data Leakage),评估结果虚高;正确做法是用验证集调参,测试集只在最后用一次。
2. 认为训练集准确率高就是好模型。错在忽略泛化;训练集 99% 而测试集 60% 往往意味着过拟合。
3. 混淆 AI、ML、DL。正确理解是三者为包含关系,深度学习只是机器学习里基于神经网络的一类方法。
4. 认为数据越多、模型越复杂一定越好。复杂模型在数据不足时更易过拟合,需配合正则化(Regularization)与更多数据。
5. 把相关当作因果。模型学到的是统计相关性,不等于因果关系,部署时要警惕虚假特征。
6. 误以为梯度下降一定收敛到全局最优。对非凸损失(如神经网络)只能保证收敛到局部最优或鞍点附近,且依赖学习率与初始化。

## 六、与其他知识点的联系

前置知识:线性代数(向量/矩阵运算)、微积分(导数与梯度)、概率统计(期望、分布、最大似然估计),以及基本的 Python 编程。这些是理解损失函数与优化的基础。

横向联系:本主题中的"损失 + 梯度下降"是几乎所有监督学习算法的统一框架,逻辑回归、支持向量机(SVM)、神经网络都可纳入其中。

后续延伸:进入深度学习需掌握反向传播(Backpropagation)、卷积神经网络(CNN,见 CS231n)、循环网络与 Transformer;评估方向延伸到精确率/召回率、ROC-AUC;工程方向延伸到特征工程、交叉验证、超参数搜索与模型部署(MLOps)。

## 七、自测题(含参考答案)

**1.(判断)** 深度学习是与机器学习并列的、互不包含的两个领域。
参考答案:错误。解析:深度学习是机器学习的一个子集(基于多层神经网络),三者为 AI ⊃ ML ⊃ DL 的包含关系。

**2.(选择)** 下列哪种情形最可能是过拟合?
A. 训练误差高、测试误差高 B. 训练误差低、测试误差高 C. 训练误差低、测试误差低 D. 训练误差高、测试误差低
参考答案:B。解析:过拟合表现为模型在训练集上很好但泛化差;A 是欠拟合,C 是理想情况,D 在常规设定下基本不会出现。

**3.(简答)** 为什么测试集不能参与训练或调参?
参考答案:测试集用于无偏估计模型的泛化能力。若它参与训练或调参,模型会间接"见过"测试数据,导致数据泄露,评估结果偏乐观,无法反映真实部署表现。

**4.(计算)** 一元线性回归 $\hat{y}=wx$,样本 $(x,y)=(2,6)$,当前 $w=1$,学习率 $\eta=0.1$,用单样本 MSE 损失 $L=(\hat{y}-y)^2$ 做一步更新,求更新后的 $w$。
参考答案:$w=2.6$。解析:$\hat{y}=1\times2=2$,梯度 $\frac{\partial L}{\partial w}=2(\hat{y}-y)x=2(2-6)(2)=-16$,更新 $w:=1-0.1\times(-16)=1+1.6=2.6$。注意:若按此式得 $2.6$;若损失带 $\frac{1}{2}$ 系数则梯度为 $-8$,结果为 $1.8$。务必明确损失定义后再计算。
