# 线性回归 Linear Regression

## 一、概念与直觉

线性回归是一种**监督学习(supervised learning)**中的**回归(regression)**方法:它假设目标变量 \$y\$ 与输入特征 \$x\$ 之间存在近似的线性关系,通过学习一组权重(weights)来用特征的加权和预测一个连续值。

可以把它想象成"画一条最贴合数据的直线"。比如你手上有一堆点(房屋面积,房价),把它们画在平面上,大致沿一个方向延伸。线性回归要做的,就是找一条直线 \$y = wx + b\$,让所有点到这条直线的"竖直距离"整体最小。在高维特征下,直线变成超平面(hyperplane),但思想一致:用线性组合去拟合数据。

它之所以是机器学习的"第一课",是因为它形式简单、有闭式解、可解释性强,同时又完整地体现了"模型假设—损失函数—优化求解"这条主线,是理解逻辑回归、神经网络等更复杂模型的基石。

## 二、核心知识点

1. **模型形式**:\$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + b = \mathbf{w}^\top \mathbf{x} + b\$,其中 \$\mathbf{w}\$ 是权重,\$b\$ 是偏置(bias/intercept)。
2. **线性的含义**:指对**参数**线性,而非对特征线性。把 \$x\$ 换成 \$x^2\$ 仍属线性回归(多项式回归)。
3. **损失函数**:最常用**均方误差(MSE, Mean Squared Error)**,衡量预测值与真实值的平方差。
4. **最小二乘法(OLS, Ordinary Least Squares)**:在 MSE 下求解参数的经典方法,存在闭式解。
5. **两种求解路径**:闭式解(正规方程,normal equation)与迭代优化(梯度下降,gradient descent)。
6. **基本假设**:误差近似独立同分布、均值为零、同方差;特征间不应高度共线(multicollinearity)。
7. **概率视角**:假设噪声服从高斯分布时,最小化 MSE 等价于**极大似然估计(MLE)**。
8. **正则化(regularization)**:加 L2 惩罚得到岭回归(Ridge),加 L1 惩罚得到 Lasso,用于抑制过拟合并做特征选择。
9. **特征缩放**:梯度下降前通常需归一化/标准化特征,以加快收敛。
10. **评价指标**:常用 MSE、RMSE、MAE 与决定系数 \$R^2\$。

## 三、关键公式 / 原理

模型:\$\hat{y}^{(i)} = \mathbf{w}^\top \mathbf{x}^{(i)} + b\$。

损失函数(MSE,含 \$1/2\$ 仅为求导方便):
\$L(\mathbf{w}, b) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2\$
其中 \$m\$ 是样本数,\$i\$ 是样本下标。

梯度下降更新规则:
\$w_j := w_j - \eta \frac{\partial L}{\partial w_j}\$,其中 \$\frac{\partial L}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}(\hat{y}^{(i)} - y^{(i)}) x_j^{(i)}\$,\$\eta\$ 为学习率(learning rate)。

正规方程(闭式解,把 \$b\$ 吸收进 \$\mathbf{w}\$ 并给 \$X\$ 增广一列 1):
\$\mathbf{w} = (X^\top X)^{-1} X^\top \mathbf{y}\$
其中 \$X \in \mathbb{R}^{m\times(d+1)}\$ 是设计矩阵,\$\mathbf{y}\$ 是真实值向量。当 \$X^\top X\$ 可逆时直接得到全局最优;不可逆时可用伪逆或加正则项。

## 四、典型例子 / 推导

设一维数据:\$x = [1, 2, 3]\$,\$y = [2, 2, 4]\$,模型 \$\hat{y} = wx + b\$。用最小二乘的闭式公式:
\$w = \dfrac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}\$,\$b = \bar{y} - w\bar{x}\$。

计算:\$\bar{x} = 2\$,\$\bar{y} = 8/3 \approx 2.667\$。
- 分子:\$(1-2)(2-2.667) + (2-2)(2-2.667) + (3-2)(4-2.667) = 0.667 + 0 + 1.333 = 2\$。
- 分母:\$(1-2)^2 + (2-2)^2 + (3-2)^2 = 1 + 0 + 1 = 2\$。

所以 \$w = 2/2 = 1\$,\$b = 2.667 - 1\times2 = 0.667\$。拟合直线为 \$\hat{y} = x + 0.667\$。

验证预测:\$x=1 \to 1.667\$,\$x=2 \to 2.667\$,\$x=3 \to 3.667\$;残差为 \$0.333, -0.667, 0.333\$,MSE \$= \frac{1}{3}(0.111+0.444+0.111) \approx 0.222\$。这条线在平方误差意义下已是最优,任何其他 \$w, b\$ 都会得到更大的 MSE。

## 五、常见误区

1. **以为"线性回归"要求特征与 y 是直线关系**:错。它要求对参数线性,可以用多项式或其他变换特征拟合曲线。
2. **混淆相关与因果**:回归系数显著不等于特征"导致"了 y,只说明统计关联。
3. **梯度下降不做特征缩放**:各特征量纲差异大时收敛极慢甚至震荡,应先标准化。
4. **认为正规方程永远优于梯度下降**:\$(X^\top X)^{-1}\$ 计算约 \$O(d^3)\$,特征维度很高时反而是梯度下降更划算。
5. **学习率随意设置**:\$\eta\$ 过大会发散,过小则收敛慢;需要调参或用学习率衰减。
6. **\$R^2\$ 越大模型越好**:增加特征几乎总会抬高 \$R^2\$,可能是过拟合;应看调整后 \$R^2\$ 或验证集表现。

## 六、与其他知识点的联系

**前置知识**:线性代数(向量、矩阵、矩阵求逆)、微积分(偏导、梯度)、概率统计(期望、方差、高斯分布、极大似然)。

**横向联系**:把线性输出经过 sigmoid 函数即得到**逻辑回归(logistic regression)**,用于分类;线性回归是不含隐藏层、不加激活函数的最简神经网络。

**后续延伸**:正则化(Ridge / Lasso / Elastic Net)、广义线性模型(GLM)、核方法、以及多层神经网络。理解"模型—损失—优化"三件套后,可平滑过渡到深度学习的训练范式。

## 七、自测题(含参考答案)

**1.(判断)** 多项式回归(如 \$\hat{y} = w_1 x + w_2 x^2 + b\$)不属于线性回归。
**参考答案**:错误。**解析**:线性回归的"线性"指对参数 \$w\$ 线性;\$x^2\$ 只是一个新特征,模型对参数仍是线性的,故仍属线性回归。

**2.(选择)** 关于梯度下降的学习率 \$\eta\$,下列正确的是( )。
A. 越大越好 B. 越小越好 C. 过大可能发散,过小收敛慢 D. 与收敛无关
**参考答案**:C。**解析**:\$\eta\$ 控制每步更新幅度,过大越过最优点甚至发散,过小则迭代次数过多。

**3.(简答)** 简述何时倾向用正规方程、何时用梯度下降。
**参考答案**:特征维度 \$d\$ 较小(如几千以内)且 \$X^\top X\$ 可逆时,正规方程一步得最优,简单可靠;当 \$d\$ 很大、样本巨大或矩阵接近奇异时,\$O(d^3)\$ 求逆代价过高,应用(随机)梯度下降。

**4.(计算)** 数据 \$x=[0,1,2]\$,\$y=[1,3,5]\$,用最小二乘求 \$w, b\$。
**参考答案**:\$w=2, b=1\$。**解析**:\$\bar{x}=1,\bar{y}=3\$;分子 \$=(-1)(-2)+0+ (1)(2)=4\$,分母 \$=1+0+1=2\$,故 \$w=4/2=2\$,\$b=3-2\times1=1\$,拟合直线 \$\hat{y}=2x+1\$ 完美过三点,MSE 为 0。
