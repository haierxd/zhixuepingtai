# 神经网络基础(MLP与激活函数) Neural Network Basics (MLP & Activations)

## 一、概念与直觉

多层感知机(Multi-Layer Perceptron, MLP)是最基础的前馈神经网络(feed-forward network):由输入层、若干隐藏层(hidden layer)和输出层组成,每层由若干神经元(neuron)构成,相邻层之间全连接(fully connected)。每个神经元先对输入做加权求和并加偏置(bias),再经过一个非线性的激活函数(activation function)输出。

直觉上,可以把单个神经元想象成一个"打分器":它给每个输入特征分配一个权重,综合打分,再用激活函数决定"激活的强度"。单层只能划出一条直线(线性决策边界),而把许多神经元层层堆叠,就能把简单的直线弯折、拼接成任意复杂的曲面——这正是 MLP 能逼近复杂函数的来源。

关键之处在于"非线性"。如果去掉激活函数,无论堆多少层,复合的仍是线性变换,等价于一个单层线性模型;激活函数引入的非线性,才让深层网络具备表达能力。通用逼近定理(universal approximation theorem)指出,带非线性激活的单隐藏层 MLP 在隐藏单元足够多时,可以以任意精度逼近紧集上的连续函数。

## 二、核心知识点

1. **神经元计算**:单个神经元输出 $a = \sigma(w^\top x + b)$,其中 $w$ 是权重向量,$b$ 是偏置,$\sigma$ 是激活函数。
2. **层的向量化**:第 $l$ 层计算为 $z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$,$a^{(l)} = \sigma(z^{(l)})$,用矩阵表示便于并行计算。
3. **前向传播(forward propagation)**:从输入逐层计算到输出,得到预测值与损失。
4. **激活函数提供非线性**:无非线性激活的多层网络会塌缩为单层线性模型。
5. **常见激活函数**:Sigmoid、Tanh、ReLU、Leaky ReLU、GELU 等,各有适用场景与缺陷。
6. **损失函数(loss)**:回归常用均方误差(MSE),多分类常用交叉熵(cross-entropy)配合 Softmax。
7. **反向传播(backpropagation)**:利用链式法则(chain rule)从输出层向输入层逐层计算梯度。
8. **梯度下降(gradient descent)**:用梯度更新参数 $w := w - \eta \nabla L$,$\eta$ 为学习率。
9. **参数初始化**:权重需随机初始化(如 Xavier/He 初始化)以打破对称性,偏置常初始化为 0。
10. **过拟合与正则化**:深层网络容量大,需配合 L2 正则、Dropout、早停等手段。

## 三、关键公式 / 原理

**前向传播(逐层)**:
$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = \sigma(z^{(l)})$$
其中 $a^{(0)} = x$ 为输入,$W^{(l)}$ 是第 $l$ 层权重矩阵,$b^{(l)}$ 是偏置向量。

**常见激活函数**:
- Sigmoid:$\sigma(z) = \dfrac{1}{1+e^{-z}}$,导数 $\sigma'(z) = \sigma(z)(1-\sigma(z))$,输出范围 $(0,1)$。
- Tanh:$\tanh(z) = \dfrac{e^z - e^{-z}}{e^z + e^{-z}}$,输出范围 $(-1,1)$,零中心。
- ReLU:$\mathrm{ReLU}(z) = \max(0, z)$,导数为 $1\,(z>0)$ 或 $0\,(z<0)$。

**参数更新(梯度下降)**:
$$w := w - \eta \frac{\partial L}{\partial w}$$
$\eta$ 为学习率,$L$ 为损失,$\dfrac{\partial L}{\partial w}$ 为损失对权重的梯度。

**反向传播核心(链式法则)**:记 $\delta^{(l)} = \dfrac{\partial L}{\partial z^{(l)}}$,则
$$\delta^{(L)} = \nabla_a L \odot \sigma'(z^{(L)}), \quad \delta^{(l)} = (W^{(l+1)\top}\delta^{(l+1)}) \odot \sigma'(z^{(l)})$$
$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} a^{(l-1)\top}, \quad \frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$
其中 $\odot$ 表示逐元素相乘。

## 四、典型例子 / 推导

考虑一个最小网络:1 个输入 $x=1$,1 个隐藏神经元,1 个输出,均用 Sigmoid,目标 $y=1$,损失用 $L=\tfrac{1}{2}(a^{(2)}-y)^2$。设 $w^{(1)}=0.5,\ b^{(1)}=0,\ w^{(2)}=0.5,\ b^{(2)}=0$,学习率 $\eta=1$。

**前向**:
$z^{(1)} = 0.5\times 1 + 0 = 0.5$,$a^{(1)} = \sigma(0.5) \approx 0.6225$。
$z^{(2)} = 0.5\times 0.6225 = 0.3112$,$a^{(2)} = \sigma(0.3112) \approx 0.5772$。
损失 $L = \tfrac{1}{2}(0.5772-1)^2 \approx 0.0894$。

**反向**:
$\delta^{(2)} = (a^{(2)}-y)\cdot a^{(2)}(1-a^{(2)}) = (-0.4228)(0.5772)(0.4228) \approx -0.1032$。
$\dfrac{\partial L}{\partial w^{(2)}} = \delta^{(2)} a^{(1)} \approx -0.1032\times 0.6225 \approx -0.0642$。
$\delta^{(1)} = w^{(2)}\delta^{(2)}\cdot a^{(1)}(1-a^{(1)}) = 0.5\times(-0.1032)\times 0.6225\times 0.3775 \approx -0.0121$。
$\dfrac{\partial L}{\partial w^{(1)}} = \delta^{(1)} x \approx -0.0121$。

**更新**:$w^{(2)} := 0.5 - 1\times(-0.0642) = 0.5642$;$w^{(1)} := 0.5 - 1\times(-0.0121) = 0.5121$。权重均增大,使下一次输出更接近 1,损失下降。

## 五、常见误区

1. **"激活函数可有可无"**:错。去掉非线性激活,多层网络等价于单层线性模型,失去表达复杂函数的能力。
2. **"层数越多一定越好"**:错。过深会带来梯度消失/爆炸、过拟合与优化困难,需配合归一化、残差等技术。
3. **"ReLU 没有梯度问题"**:不全对。ReLU 缓解了梯度消失,但存在"死亡 ReLU"(神经元恒输出 0、梯度为 0),可用 Leaky ReLU 等缓解。
4. **"权重可以全部初始化为同一常数(如 0)"**:错。同层神经元会完全对称、学到相同特征,必须随机初始化打破对称性。
5. **"Softmax 是激活函数,可放在隐藏层"**:不妥。Softmax 通常只用于多分类输出层,把分数转成概率分布;隐藏层一般用 ReLU 等。
6. **"学习率越大收敛越快"**:错。学习率过大会震荡甚至发散,过小则收敛慢,需要调参或用自适应优化器(如 Adam)。

## 六、与其他知识点的联系

**前置知识**:线性代数(矩阵乘法、向量运算)、微积分(偏导数、链式法则)、概率与信息论(交叉熵)、感知机与逻辑回归(单层线性模型的推广)。

**后续延伸**:反向传播是后续所有深度网络训练的基础;优化方面延伸出 SGD、Momentum、Adam 等优化器;为缓解 MLP 的缺陷发展出卷积神经网络(CNN,处理图像的局部性与权重共享)、循环神经网络(RNN)与 Transformer;正则化方向延伸到 Dropout、Batch Normalization;表达能力方面对应通用逼近定理。MLP 至今仍作为 Transformer 等现代架构中的前馈子层广泛使用。

## 七、自测题(含参考答案)

**1.(判断)** 若一个三层网络所有激活函数都是恒等函数 $\sigma(z)=z$,它仍能表达非线性决策边界。
参考答案:错。
解析:恒等激活下逐层复合仍是线性变换,整个网络等价于单层线性模型,只能表达线性边界。

**2.(选择)** 关于 ReLU 的描述,正确的是:
A. 输出范围为 $(-1,1)$ B. 在 $z<0$ 时梯度为 0,可能导致神经元"死亡" C. 它是零中心的 D. 它带来梯度消失问题比 Sigmoid 更严重
参考答案:B。
解析:ReLU $=\max(0,z)$,负半轴梯度为 0,可能出现死亡 ReLU;它非零中心,正半轴梯度恒为 1,反而缓解梯度消失。

**3.(简答)** 为什么权重不能初始化为全 0,而偏置通常可以?
参考答案:权重全 0(或同一常数)会使同层神经元前向输出与反向梯度完全相同,始终对称、学到相同特征,网络退化。需随机初始化打破对称性。偏置不参与对称性破坏的关键作用,且各神经元权重已不同,故偏置初始化为 0 通常无碍。

**4.(计算)** 给定 Sigmoid 神经元,输入 $x=2,\ w=1,\ b=-1$,求输出 $a$ 及该点导数 $\sigma'(z)$(保留四位小数)。
参考答案:$z = 1\times 2 + (-1) = 1$;$a = \sigma(1) = \dfrac{1}{1+e^{-1}} \approx 0.7311$;$\sigma'(z) = a(1-a) \approx 0.7311\times 0.2689 \approx 0.1966$。
解析:先算线性部分 $z$,代入 Sigmoid 得输出,再用导数公式 $\sigma'(z)=\sigma(z)(1-\sigma(z))$。
