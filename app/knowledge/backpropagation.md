# 反向传播 Backpropagation

## 一、概念与直觉

反向传播(Backpropagation,简称 BP)是一种**高效计算神经网络损失函数对所有参数梯度**的算法。它本质上是微积分链式法则(chain rule)在计算图上的系统化应用,使得我们可以用一次"前向 + 反向"遍历就求出全部参数的偏导数,再交给梯度下降去更新参数。它本身**不是**优化算法,只是为优化算法提供梯度。

可以用工厂流水线的类比建立直觉:前向传播(forward pass)像原料从入口逐道工序加工,最终在出口得到产品并与标准对比、算出"次品损失";反向传播则是从出口开始,把"这一批的损失应该归咎于哪道工序、归咎多少"逐级往回追责——每一层根据下游传回的"责任"(误差信号)和自己的局部影响,算出该为损失负多少责,并继续把责任分摊给上游。

它的价值在于**计算复杂度**。若对每个参数单独用数值差分求梯度,代价随参数量线性放大且需多次前向;而 BP 利用中间结果的复用,使求全部梯度的代价与一次前向传播同阶。这正是深度网络可训练的工程前提。

## 二、核心知识点

1. BP 求的是损失 L 对参数(权重 w、偏置 b)的偏导数 ∂L/∂w,梯度下降负责用这些导数更新参数,二者分工不同。
2. BP 依赖**链式法则**:复合函数的导数等于各层局部导数之乘积。
3. 训练一步包含三个阶段:前向传播算出预测与损失、反向传播算出梯度、参数更新。
4. 前向传播必须**缓存中间激活值**(如各层输入、加权和 z),反向传播会复用它们,这是空间换时间。
5. 误差信号(常记作 δ)从输出层向输入层逐层回传,每层的 δ 由下游 δ 与本层权重、激活函数导数共同决定。
6. 某层权重的梯度 = 该层误差 δ 与该层输入激活值的乘积,结构上"上游激活 × 下游误差"。
7. 激活函数必须可导(或几乎处处可导,如 ReLU),其导数直接进入 δ 的计算。
8. BP 是**自动微分(automatic differentiation)反向模式**的特例,现代框架(PyTorch、TensorFlow)用计算图自动实现。
9. 梯度消失/爆炸是 BP 在深层网络中的固有现象:连乘的局部导数若普遍 <1 会消失、>1 会爆炸。
10. BP 不要求损失函数全局凸,它只保证给出当前点的梯度方向,收敛到的可能是局部极小或鞍点。

## 三、关键公式 / 原理

以 L 层全连接网络为例,符号:第 l 层加权输入 $z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$,激活 $a^{(l)} = \sigma(z^{(l)})$,σ 为激活函数,L 为损失。

输出层误差:

$$\delta^{(L)} = \nabla_a L \odot \sigma'(z^{(L)})$$

其中 $\nabla_a L$ 是损失对输出激活的导数,⊙ 表示按元素相乘(Hadamard product)。

误差反向递推:

$$\delta^{(l)} = \left( (W^{(l+1)})^\top \delta^{(l+1)} \right) \odot \sigma'(z^{(l)})$$

下游误差先经下一层权重的转置"传回",再乘本层激活导数。

参数梯度:

$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^\top, \qquad \frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$

参数更新(梯度下降):

$$w := w - \eta \nabla L$$

η 为学习率(learning rate)。直觉:权重梯度由"下游误差"与"上游输入"外积而成,偏置梯度就等于误差本身。

## 四、典型例子 / 推导

考虑最简标量网络:输入 x=1,一层线性 + sigmoid,目标 y=0,损失为平方误差 $L=\tfrac12(a-y)^2$。设 w=0.5,b=0,$\sigma(z)=\frac{1}{1+e^{-z}}$。

**前向传播**

- z = w·x + b = 0.5·1 + 0 = 0.5
- a = σ(0.5) ≈ 0.6225
- L = 0.5·(0.6225 − 0)² ≈ 0.1937

**反向传播**

- ∂L/∂a = a − y = 0.6225
- σ'(z) = a(1−a) = 0.6225·0.3775 ≈ 0.2350
- δ = ∂L/∂a · σ'(z) ≈ 0.6225·0.2350 ≈ 0.1463
- ∂L/∂w = δ·x ≈ 0.1463·1 = 0.1463
- ∂L/∂b = δ ≈ 0.1463

**参数更新**(取 η=0.1)

- w ← 0.5 − 0.1·0.1463 ≈ 0.4854
- b ← 0 − 0.1·0.1463 ≈ −0.0146

可验证:更新后再前向一次,a 会略微变小、损失下降,说明梯度方向正确。

## 五、常见误区

1. **把 BP 等同于训练算法**:BP 只算梯度,真正更新参数的是 SGD/Adam 等优化器,二者要分清。
2. **忘记乘激活函数导数**:δ 回传时必须乘 σ'(z),漏掉它会得到错误梯度;这也是为何饱和激活会让梯度趋零。
3. **认为梯度消失是 BP 算法的 bug**:它是链式连乘的数学必然,应通过 ReLU、残差连接、归一化等结构缓解,而非"修复 BP"。
4. **混淆 z 与 a 求导**:σ'(z) 是对加权输入 z 求导,不是对激活 a;实现时 sigmoid 可写成 a(1−a),但概念上仍是对 z 的导数。
5. **以为反向传播是数值差分**:BP 是解析(符号)求导的高效组织,不是用 (L(w+ε)−L(w))/ε 近似;数值梯度仅用于校验。
6. **更新参数时用错激活**:权重梯度用的是**上一层的激活** $a^{(l-1)}$,不是本层激活,方向上容易搞反。

## 六、与其他知识点的联系

前置知识:多元微积分中的**偏导数与链式法则**、线性代数中的矩阵乘法与转置、神经网络的**前向传播**结构、损失函数(MSE、交叉熵)、激活函数(sigmoid、ReLU、tanh)及其导数。

并列/支撑知识:**梯度下降**及其变体(SGD、Mini-batch、Momentum、Adam)消费 BP 产出的梯度;**计算图**与**自动微分**是 BP 的现代抽象与工程实现。

后续延伸:卷积网络与循环网络中的 BP 变体(如 RNN 的 BPTT,沿时间展开反向传播)、梯度消失/爆炸的应对(残差网络 ResNet、批归一化 BatchNorm、梯度裁剪)、以及框架层面的 autograd 机制。掌握 BP 是理解几乎所有深度学习训练流程的钥匙。

## 七、自测题(含参考答案)

**1.(判断)** 反向传播本身就是一种优化算法,能直接最小化损失函数。
参考答案:错。解析:BP 只负责高效计算梯度 ∂L/∂w,最小化损失由梯度下降等优化器完成,二者职责不同。

**2.(选择)** 反向传播能高效计算梯度,最根本的原因是( )。
A. 它使用了 GPU 并行
B. 它通过链式法则复用前向传播缓存的中间结果,避免重复计算
C. 它对每个参数单独做数值差分
D. 它跳过了激活函数的导数
参考答案:B。解析:A 是工程加速,非根本原因;C 恰是 BP 要避免的低效做法;D 错误,δ 必须乘激活导数。BP 的关键是中间结果复用,使求全部梯度与一次前向同阶。

**3.(简答)** 为什么深层网络容易出现梯度消失?请结合 BP 的公式说明,并举一种缓解方法。
参考答案:误差按 $\delta^{(l)} = ((W^{(l+1)})^\top \delta^{(l+1)}) \odot \sigma'(z^{(l)})$ 逐层回传,涉及多层局部导数的连乘。若激活导数普遍小于 1(如 sigmoid 饱和区 σ'≤0.25),连乘后趋于 0,浅层几乎得不到梯度。缓解方法:改用 ReLU、引入残差连接、使用 BatchNorm 或合适的权重初始化。

**4.(计算)** 单神经元 σ 为 sigmoid,输入 x=2,w=1,b=−1,目标 y=1,损失 $L=\tfrac12(a-y)^2$。求 ∂L/∂w。
参考答案:z = 1·2 + (−1) = 1;a = σ(1) ≈ 0.7311;∂L/∂a = a−y ≈ −0.2689;σ'(z)=a(1−a) ≈ 0.1966;δ = (−0.2689)·0.1966 ≈ −0.0529;∂L/∂w = δ·x ≈ −0.0529·2 ≈ −0.1057。解析:梯度为负,说明增大 w 会降低损失,与目标 y=1、当前预测偏小的直觉一致。
