# 大语言模型:预训练、微调与 RAG LLMs: Pretraining, Fine-tuning & RAG

## 一、概念与直觉

大语言模型(Large Language Model, LLM)是一类以 Transformer 为骨架、在海量文本上以自监督方式训练得到的概率语言模型,其核心目标是建模文本序列的联合概率分布 $P(x_1, x_2, \dots, x_T)$。围绕 LLM 的三项关键技术——预训练(Pretraining)、微调(Fine-tuning)与检索增强生成(Retrieval-Augmented Generation, RAG)——分别解决"模型从哪里获得通用能力""如何让通用能力适配具体任务""如何让模型用上训练时没见过的新知识"这三个问题。

可以用"培养一名行业专家"来建立直觉。预训练好比让一个人通读海量书籍报刊,形成广博的语言能力和世界常识,但他不针对任何具体岗位;微调好比给这位通才做岗前培训,用少量本岗位的范例把通用能力"对齐"到具体任务(如客服、医疗问答)或特定回答风格;RAG 则好比给他配一台随时可查的资料库,回答前先去检索最新、最权威的文档,把检索结果作为依据写进答案,而不依赖记忆。

三者并非互斥:预训练提供地基,微调塑造行为,RAG 注入实时且可溯源的外部知识。实际系统常组合使用,例如在预训练基座上做指令微调,再叠加 RAG 处理企业私有或时效性强的知识。

## 二、核心知识点

1. **自监督预训练**:无需人工标注,直接从原始文本构造监督信号。主流目标是因果语言建模(Causal LM,GPT 系预测下一个 token)与掩码语言建模(Masked LM,BERT 系还原被遮盖 token)。
2. **Transformer 与自注意力**:LLM 的主干是 Transformer,自注意力(Self-Attention)让每个位置都能加权聚合全序列信息,复杂度为 $O(n^2 d)$,是长上下文成本高的根源。
3. **Tokenization 与 Embedding**:文本先经 BPE/WordPiece 等子词切分为 token,再映射为向量;模型最终输出每个 token 的概率分布。
4. **Scaling Law(规模定律)**:在数据、参数、算力充足且配比合理时,损失随规模近似幂律下降,这是"做大模型"的经验依据。
5. **微调谱系**:全参数微调(Full Fine-tuning)、参数高效微调(PEFT,如 LoRA、Adapter、Prefix-tuning),以及面向对齐的指令微调(SFT)与 RLHF/DPO。
6. **LoRA**:冻结原权重 $W$,只训练低秩增量 $\Delta W = BA$,大幅降低显存与存储成本,推理时可合并。
7. **RAG 流程**:Query → 检索(向量召回/BM25)→ 重排序 → 将上下文拼入 Prompt → 生成,核心是"先检索后生成"。
8. **向量检索**:文档与查询都被编码为稠密向量,用余弦相似度/内积在向量库(如 FAISS)中做近似最近邻(ANN)搜索。
9. **幻觉(Hallucination)与对齐**:模型可能生成流畅但失实的内容;RAG 通过提供可溯源证据缓解幻觉,RLHF/DPO 让输出更符合人类偏好。
10. **上下文窗口与提示工程**:模型一次能处理的 token 数有限,RAG、Prompt 设计都受其约束。

## 三、关键公式 / 原理

**自回归语言建模目标**:将序列概率按链式法则分解,并最小化负对数似然(交叉熵):
$$L = -\sum_{t=1}^{T} \log P_\theta(x_t \mid x_1, \dots, x_{t-1})$$

**自注意力**:给定查询、键、值矩阵 $Q, K, V$:
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
其中 $d_k$ 是键向量维度,$\sqrt{d_k}$ 用于缩放点积、稳定梯度;softmax 给出对各位置的注意力权重。

**参数更新**:用梯度下降优化(实际多用 AdamW):$w := w - \eta \nabla_w L$,$\eta$ 为学习率。

**LoRA 低秩分解**:前向变为 $h = Wx + \Delta W x = Wx + BAx$,其中 $W\in\mathbb{R}^{d\times d}$ 冻结,$B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times d}$,秩 $r \ll d$,可训练参数从 $d^2$ 降到 $2rd$。

**RAG 生成**:在检索到的上下文 $C$ 条件下生成答案:$P(y \mid x) = P_\theta(y \mid x, C)$,其中 $C = \text{Retrieve}(x)$ 是与查询最相关的若干文档片段。

## 四、典型例子 / 推导

以 LoRA 为例算一笔"省了多少"的账。设某线性层维度 $d = 4096$(典型隐藏维度)。

- 全参数微调该层需训练参数:$d \times d = 4096 \times 4096 = 16{,}777{,}216 \approx 1.68\times 10^7$ 个。
- 采用 LoRA,取秩 $r = 8$,可训练参数为 $2rd = 2 \times 8 \times 4096 = 65{,}536 \approx 6.55\times 10^4$ 个。
- 占比:$\dfrac{65{,}536}{16{,}777{,}216} \approx 0.39\%$。

也就是说,LoRA 只用约 0.4% 的可训练参数就能逼近全参数微调的效果,且原权重 $W$ 全程冻结,显存中无需为它保存优化器状态(Adam 通常为每个可训练参数额外存约 2 份动量),节省尤为显著。推理时把 $BA$ 加回 $W$,不增加额外延迟。

再看一次自注意力的缩放:若 $d_k = 64$,$\sqrt{d_k} = 8$。某个查询与某个键的点积原始得分为 16,缩放后变为 $16/8 = 2$,再进入 softmax。若不缩放,大维度下点积数值会很大,softmax 进入饱和区导致梯度极小,这正是除以 $\sqrt{d_k}$ 的原因。

## 五、常见误区

1. **"微调就能让模型学到新事实"**:微调主要改变模型的行为、风格和任务格式,对注入大量新事实并不可靠,还容易引发灾难性遗忘。要补充时效性/私有知识,RAG 通常更合适。
2. **"RAG 等于把文档塞进 Prompt 就行"**:RAG 的难点在检索质量(召回、重排、切块策略)。检索不准,再强的生成模型也会答错;垃圾进、垃圾出。
3. **"参数越多一定越好"**:Scaling Law 成立的前提是数据量与算力同步增长。数据不足时盲目加大模型只会过拟合或欠训练(参见 Chinchilla 关于参数与数据配比的结论)。
4. **"LoRA 改的是原始权重"**:LoRA 冻结 $W$,只训练新增的低秩矩阵 $A, B$;原权重不动,因此可以为不同任务挂载不同的 LoRA 适配器。
5. **"预训练和微调用同一种损失就没区别"**:两者都常用交叉熵,但数据来源(海量无标注 vs 少量任务/指令数据)、目标(通用语言能力 vs 任务对齐)和规模完全不同。
6. **"RAG 能彻底消除幻觉"**:RAG 显著降低幻觉并提供可溯源证据,但若检索内容本身有误,或模型忽略上下文,仍会出错。

## 六、与其他知识点的联系

**前置知识**:概率与信息论(交叉熵、最大似然估计)、神经网络与反向传播、词向量(Word2Vec/Embedding)、Transformer 与注意力机制、梯度下降与优化器(SGD/Adam)。理解这些是读懂本主题公式的基础。

**横向关联**:RAG 与信息检索(TF-IDF、BM25、向量检索 ANN)深度交叉;微调中的 RLHF 与强化学习(策略梯度、奖励模型)相连;PEFT 与矩阵低秩分解、模型压缩相关。

**后续延伸**:对齐技术(RLHF、DPO、Constitutional AI)、长上下文与高效注意力(FlashAttention、稀疏注意力)、多模态大模型、Agent 与工具调用、模型评测(困惑度 Perplexity、基准测试)、推理优化(量化、KV Cache、投机解码)。掌握本主题后,可顺势进入"如何让 LLM 更可控、更高效、更可信"的研究方向。

## 七、自测题(含参考答案)

**1.(选择)** 下列关于因果语言建模(Causal LM)的说法,正确的是:
A. 它需要人工标注每个 token 的标签 　B. 它预测被掩盖的中间 token
C. 它根据前文预测下一个 token,属于自监督 　D. 它只能用于分类任务

参考答案:C。
解析:Causal LM(GPT 系)用前文预测下一个 token,监督信号来自文本自身,无需人工标注,属自监督;预测中间被掩盖 token 的是 Masked LM(BERT 系)。

**2.(判断)** 要让 LLM 掌握公司最新发布的内部规章,优先选择继续做大规模微调,而不是 RAG。

参考答案:错误。
解析:微调对注入具体、时效性事实不可靠且成本高、易遗忘;最新且私有的知识更适合用 RAG 在生成时检索注入,既准确又可随文档更新而即时生效。

**3.(计算)** 某线性层维度 $d = 2048$,使用 LoRA 且秩 $r = 16$。求可训练参数量,并计算其相对全参数微调该层的比例。

参考答案:LoRA 可训练参数 $= 2rd = 2\times 16\times 2048 = 65{,}536$;全参数微调 $= d^2 = 2048^2 = 4{,}194{,}304$;比例 $\approx 65{,}536 / 4{,}194{,}304 \approx 1.56\%$。
解析:LoRA 用两个低秩矩阵 $A(r\times d)$ 与 $B(d\times r)$ 表示增量,参数量 $2rd$ 随 $r$ 线性增长,远小于 $d^2$。

**4.(简答)** 自注意力公式中为什么要除以 $\sqrt{d_k}$?简述其作用。

参考答案:用于缩放点积。随着键向量维度 $d_k$ 增大,$QK^\top$ 的数值方差随之增大,过大的得分会使 softmax 输出趋于"非 0 即 1"(进入饱和区),导致梯度极小、训练困难。除以 $\sqrt{d_k}$ 将点积方差归一化到合理范围,稳定梯度、加速收敛。
