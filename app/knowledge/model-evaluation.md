# 模型评估指标 Model Evaluation Metrics

## 一、概念与直觉

模型评估指标(evaluation metrics)是一组用来量化模型预测好坏的数值。训练得到一个模型后,我们必须用客观的数字回答"它到底有多好",这些数字就是评估指标。不同任务(分类、回归、排序)、不同业务目标,需要的指标也不同。

直觉上,可以把评估指标想象成考试的"评分标准"。同一份答卷,用"答对题数"和"扣分制"打分会得到不同侧重:前者只看做对多少,后者还惩罚错误。比如医院筛查癌症,漏诊(把病人判为健康)的代价远大于误诊,这时就不能只看"总体正确率",而要看"有病的人里被查出来的比例"。

更进一步,评估指标的选择本身就是一种价值判断。准确率(accuracy)在类别不平衡时具有欺骗性:若 99% 样本为负类,模型全猜负类也有 99% 准确率,却毫无用处。因此理解每个指标"奖励什么、惩罚什么",比死记公式更重要。

## 二、核心知识点

1. **混淆矩阵(confusion matrix)** 是分类评估的基础,由 TP、FP、FN、TN 四个计数构成,几乎所有分类指标都从它推导。
2. **准确率 Accuracy** = 预测正确的样本数 / 总样本数;直观但在类别不平衡时不可靠。
3. **精确率 Precision** 关注"预测为正的里有多少真的是正",回答"报警有多准"。
4. **召回率 Recall(查全率/灵敏度)** 关注"真正例里有多少被找出来",回答"漏了多少"。
5. **F1 分数** 是 Precision 与 Recall 的调和平均,用于在二者间取平衡;更一般的 F-beta 可调节侧重。
6. **ROC 曲线与 AUC**:以不同阈值下的 TPR-FPR 作图,AUC 衡量模型对正负样本的整体排序能力,对类别不平衡相对稳健。
7. **PR 曲线**:在正类稀少时比 ROC 更敏感,横轴 Recall、纵轴 Precision。
8. **阈值依赖性**:Precision/Recall/F1/Accuracy 都依赖分类阈值,而 AUC 不依赖具体阈值。
9. **回归指标**:MAE、MSE、RMSE 衡量误差大小,R²(决定系数)衡量模型解释方差的比例。
10. **多分类扩展**:可用 macro 平均(各类等权)、micro 平均(按样本汇总)、weighted 平均(按类别样本数加权)。

## 三、关键公式 / 原理

设混淆矩阵中:TP(真正例)、FP(假正例)、FN(假负例)、TN(真负例)。

- 准确率:$Accuracy = \dfrac{TP + TN}{TP + TN + FP + FN}$
- 精确率:$Precision = \dfrac{TP}{TP + FP}$
- 召回率:$Recall = \dfrac{TP}{TP + FN}$
- F1 分数:$F_1 = 2 \cdot \dfrac{Precision \cdot Recall}{Precision + Recall}$(调和平均)
- F-beta:$F_\beta = (1+\beta^2)\dfrac{Precision \cdot Recall}{\beta^2 \cdot Precision + Recall}$,$\beta>1$ 偏重 Recall。
- ROC 坐标:$TPR = Recall = \dfrac{TP}{TP+FN}$,$FPR = \dfrac{FP}{FP+TN}$;AUC 是 ROC 曲线下面积,等价于"随机取一对正负样本,正样本得分高于负样本的概率"。

回归任务(设真实值 $y_i$,预测值 $\hat{y}_i$,样本数 $n$,均值 $\bar{y}$):

- 平均绝对误差:$MAE = \dfrac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$
- 均方误差:$MSE = \dfrac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$,$RMSE = \sqrt{MSE}$
- 决定系数:$R^2 = 1 - \dfrac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$,$R^2=1$ 表示完美拟合,$R^2=0$ 表示与"恒预测均值"持平。

## 四、典型例子 / 推导

某垃圾邮件分类器在 100 封邮件上测试(正类=垃圾邮件)。结果:实际垃圾邮件 40 封,模型查出 30 封(TP=30),漏判 10 封(FN=10);实际正常邮件 60 封,模型误判 20 封为垃圾(FP=20),正确放行 40 封(TN=40)。

逐项计算:

- Accuracy = (TP+TN)/总数 = (30+40)/100 = 0.70
- Precision = TP/(TP+FP) = 30/(30+20) = 30/50 = 0.60
- Recall = TP/(TP+FN) = 30/(30+10) = 30/40 = 0.75
- F1 = 2 × (0.60 × 0.75)/(0.60 + 0.75) = 2 × 0.45/1.35 ≈ 0.667

解读:准确率 0.70 看似尚可,但 Precision 只有 0.60,意味着每 5 封被判垃圾的邮件就有 2 封是误杀的正常邮件。对垃圾邮件场景,误杀正常邮件代价高,应优先提升 Precision(例如提高判为垃圾的阈值),哪怕牺牲一些 Recall。这说明:仅看一个数字会误导决策,必须结合业务目标看多个指标。

## 五、常见误区

1. **"准确率高就是好模型"** —— 错。类别不平衡时准确率会被多数类支配。正确理解:不平衡数据应优先看 Precision/Recall/F1 或 AUC/PR-AUC。
2. **混淆 Precision 与 Recall** —— 错。Precision 分母是"预测为正的数量"(TP+FP),Recall 分母是"真实为正的数量"(TP+FN)。记法:Precision 看"预测列",Recall 看"真实行"。
3. **"F1 是 Precision 和 Recall 的算术平均"** —— 错。F1 是调和平均,会被较小值拉低,任一指标很差时 F1 也会很差。
4. **"AUC 越高,固定阈值下的准确率一定越高"** —— 错。AUC 衡量的是排序能力,与具体阈值无关;实际部署仍需单独选阈值。
5. **"在测试集上反复调参选指标最高的模型没问题"** —— 错。这会让测试集泄漏(信息泄漏),应使用验证集调参、测试集只用一次。
6. **回归里"R² 必为正且越大越好,负数说明算错了"** —— 错。R² 可以为负,表示模型还不如直接预测均值,是真实可能的结果。

## 六、与其他知识点的联系

前置知识:概率与统计基础(条件概率、期望)、监督学习中的分类与回归任务定义、训练集/验证集/测试集划分。理解混淆矩阵需要先掌握二分类的预测输出(标签或概率分数)。

横向关联:阈值选择与 ROC/PR 曲线密切相关;类别不平衡问题(重采样、代价敏感学习)直接决定指标选择;交叉验证(cross-validation)是获得稳定指标估计的标准做法。

后续延伸:排序与推荐系统的指标(Precision@K、NDCG、MAP);信息检索评估;目标检测中的 mAP;NLP 中的 BLEU、ROUGE、Perplexity;以及统计显著性检验(用于判断两个模型的指标差异是否真实)。掌握本主题后,可进一步学习如何根据业务损失函数定制评估方案。

## 七、自测题(含参考答案)

**1.(选择)** 在 99% 样本为负类的极度不平衡数据集上,下列哪个指标最不适合单独用来评价模型?
A. F1  B. Accuracy  C. Recall  D. PR-AUC

参考答案:B。解析:全猜负类即可获得约 99% 的 Accuracy,却毫无识别正类的能力,故准确率在此场景具有欺骗性。

**2.(判断)** AUC 的取值不依赖于分类阈值的选择。( )

参考答案:正确。解析:AUC 是对所有阈值下 (FPR, TPR) 点连成曲线后的面积,刻画整体排序能力,因此与单一阈值无关。

**3.(计算)** 某模型 TP=80,FP=20,FN=40,TN=860。求 Precision、Recall 与 F1。

参考答案:Precision = 80/(80+20) = 0.80;Recall = 80/(80+40) = 80/120 ≈ 0.667;F1 = 2×(0.80×0.667)/(0.80+0.667) ≈ 2×0.533/1.467 ≈ 0.727。解析:先定位四个计数,代入公式,F1 取调和平均。

**4.(简答)** 在癌症初筛场景中,你会优先优化 Precision 还是 Recall?为什么?

参考答案:优先 Recall。解析:初筛阶段漏诊(FN)代价极高,可能延误治疗;而误诊(FP)可通过后续复查纠正,代价相对较低。因此应尽量"宁可错查、不可漏查",优先提高 Recall(可用 F-beta 中 β>1 来量化这种偏好)。
